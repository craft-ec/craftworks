Every piece is its own piece contract, at an address only the file's key can compute. A file is one root piece, then index pieces (which fragments exist and their hashes), then fragment pieces: 16 chunks per generation plus 8 coded extras, any 16 of which rebuild it. No contract can read what it holds; this page checks each piece against the root hash. In the Craftworks app the reference is not baked in: it is a row in the uploader's table (a tail contract they sign; their identity is an idlog contract), listed in Discover (a bag contract).

How this page works

This page is a website stored on Freenet, and the film is too. The only thing on this machine is a Freenet node; the page talks to it over a local WebSocket. Everything else happens in this tab: fetching pieces, checking them, decoding, decrypting and playback. Nothing is downloaded until you press ▶, and then only the fragments around the playhead.

1. ReferenceThe page holds one small reference: the video manifest's key, root hash and size. Public files are keyed by their content, so anyone with the reference can read it and nobody without it can find the pieces.
2. PiecesEvery piece lives in its own piece contract at an address computed from the key. The contract cannot read it; this page checks every piece against the root hash as it arrives.
3. CodingA file is cut into chunks, encrypted, and coded in generations of 16 with random linear network coding. A healthy chunk reads alone; a slow or missing one is rebuilt from any 16 of the generation's fragments, asked all at once.
4. ManifestThe manifest lists the renditions (HEVC 2160p to 480p, H.264 720p and 360p), each a fragmented MP4 indexed by byte and time, plus a strip of frames for the timeline.
5. PlaybackThe player picks the family your browser plays smoothly, asks four 4-second fragments at a time, and moves between renditions by measured throughput. Quality can also be chosen by hand.
6. Same codeThese are the same modules the Craftworks Video app uses (node, files, video-player, player-chrome), loaded here without accounts, tables or apps.
